# Gen Hub

One-tap launcher for all image and video generator apps across Hugging Face, Netlify, Vercel, GitHub Pages and the Runpod console.

Static single page. Installable as a PWA on iOS and Android.

- `index.html` — the launcher (all links live in the `SECTIONS` array)
- `manifest.webmanifest`, `sw.js`, `icons/` — install and offline shell
